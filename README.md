# MINI TETRIS

브라우저에서 바로 실행하는 한국어 테트리스 게임입니다. 별도 라이브러리나 빌드 과정이 필요하지 않습니다.

## 실행 방법
1. 저장소에서 `index.html` 파일을 엽니다.
2. 파일을 다운로드한 뒤 웹 브라우저로 열면 플레이할 수 있습니다.
3. GitHub Pages를 켜면 웹 주소로도 배포할 수 있습니다.

## 조작
- `←` / `→`: 좌우 이동
- `↑`: 블록 회전
- `↓`: 한 칸 빠르게 내리기
- `Space`: 즉시 떨어뜨리기
- `P`: 일시정지 / 계속하기
- 모바일: 화면 아래 방향 버튼 사용

## 기능
- 10×20 게임 보드와 7종 테트로미노
- 완성한 줄 제거, 점수 및 레벨 상승
- 다음 블록 미리보기와 낙하 위치 그림자
- 최고 점수 브라우저 로컬 저장
- 키보드와 모바일 터치 조작
- 게임 오버 및 일시정지 화면

## 기술
HTML, CSS, Canvas API, Vanilla JavaScript. 외부 의존성 없음.
